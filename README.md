# Omarchy "Lorem Ipsum"

A little omarchy menu bar app to generate lorem ipsum like texts.

Content from https://www.funnylorem.com/ or from some of the listed sources here: https://www.domestika.org/en/blog/6073-the-10-funniest-lorem-ipsum-generators or https://loremipsum.io/ultimate-list-of-lorem-ipsum-generators/

First version: choose 3 variants

UI layout from https://macmenubar.com/tiny-ipsum/ allow select multiple (a) words (b) sentences (c) paragraphs.
